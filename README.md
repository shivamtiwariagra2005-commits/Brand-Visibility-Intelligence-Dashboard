# Brand Visibility Intelligence Dashboard

## Project Overview

The Brand Visibility Intelligence Dashboard is an end-to-end data analytics project designed to analyze product
visibility, pricing, ratings, reviews, brands, platforms, discounts, and search rankings across online shopping
platforms.

The project combines product data extracted from Google Shopping using SerpApi with an additional noisy dataset. The
combined data is cleaned, transformed, analyzed using Python, stored in MySQL, and visualized through an interactive
Power BI dashboard.

---

## Feature Engineering

Additional analytical features are created during preprocessing:

### Brand

Product brands are extracted from product titles using known-brand matching with a fallback extraction method.

### Visibility Score

A visibility score is calculated using product search position. Products appearing at better search positions receive
higher visibility scores.

### Price Range

Products are classified into:

- Very Low
- Low
- Medium
- High
- Very High

A separate sorting field is used to maintain the logical price-range order in Power BI.

### Discount Percentage

Discount percentage is calculated when a valid original/MRP price is available and is greater than the current selling
price.

Missing original prices remain unavailable rather than being incorrectly treated as zero discount.

## Environment Variables

Sensitive credentials should never be committed to the repository.

Configure the following environment variables locally:

```text
SERPAPI_KEY=your_serpapi_key_here
MYSQL_PASSWORD=your_mysql_password_here
```

See `.env.example` for the required variable names.

**Never store real API keys or database passwords in GitHub.**

---

## Running the Project

### 1. Extract Fresh API Data

Run this only when fresh Google Shopping data is required:

```bash
python Extract_Data.py
```

This creates:

```text
api_raw_data.csv
```

### 2. Run the Processing Pipeline

```bash
python main.py
```

The main pipeline performs:

1. Cleaning and merging
2. Creation of `cleaned_data.csv`
3. Loading data into MySQL
4. Exploratory Data Analysis
5. Generation of EDA charts

API extraction is intentionally kept separate to avoid unnecessary API requests.

### 3. Open Power BI

Open:

```text
Brand_Visibility_Intelligence_Dashboard.pbix
```

Refresh the Power BI data connection when the underlying MySQL data has been updated.
